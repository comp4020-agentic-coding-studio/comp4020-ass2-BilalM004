- Dev server gotcha: this repo lives on a Windows-mounted path
  (`/mnt/c/...`), so WSL never fires the inotify events Vite's watcher
  relies on — edits silently don't hot-reload. Fix: launch with
  `CHOKIDAR_USEPOLLING=true pnpm dev` (an env var Vite's bundled chokidar
  reads directly), which polls mtimes instead and works across the mount
  boundary. No repo change needed, just how the server gets started.
