# Shipping checklist

Run once all content buckets above are done.

- [ ] `content-review` skill run over all content — contradiction, tone,
      policy-mismatch, thematic-drift.
- [ ] `spec/` checks revisited against real content (not just placeholders);
      `pnpm check` green.
- [ ] `PROCESS.md` written (400–600 words, cites commits).
- [ ] `pnpm check:evidence` green — STARTER_CONTENT markers gone, citations
      resolve, artwork replaced, `CLAUDE.md` present.
- [ ] `/ship` skill: flips repo public, deploys to Pages.
- [ ] Manual read-through at both marking viewports on the live URL: home, a
      few non-adjacent Crossings, an assessment, the deck, policies.
